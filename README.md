## ✦ Key Systems & Works

### 1. VeriTrust AI — Enterprise Hallucination Guardrail
*Real-time Maker-Judge dual-layer guardrail that intercepts customer-support LLM answers before reaching the user.*
- **Core Stack**: FastAPI, LangGraph, ChromaDB, Gemini API, React, TypeScript, Tailwind CSS
- **Performance**: **0.2 ms** arithmetic validation latency, zero LLM token cost on mathematical checks, **99.4%** benchmark hallucination interception rate.
- **Topology**: Breaks answers into atomic claims, verifies vector entailment against indexed policy chunks, and enforces hard-coded arithmetic checks.
- **Live Demo**: [Open Chat Application](https://veritrust-ai-gdgoc.onrender.com/chat)

### 2. AuraGuard — Emotion-Aware Encryption Engine
*Context-adaptive NLP security system that detects emotional risk and duress in text in real-time.*
- **Core Stack**: Python, Flask, NLP Sentiment Analysis, AES-256-GCM
- **Mechanics**: Dynamically configures cryptographic key exchange constraints and payload cipher parameters within sub-second cycles upon detecting duress patterns.

### 3. AICROP-DETECTOR — Smart Farming & 3D Web Platform
*AI Plant Doctor for instant crop leaf disease diagnosis and interactive agricultural planning.*
- **Core Stack**: React, Vite, Three.js, React Three Fiber, Zustand, Framer Motion, GSAP
- **Highlights**: Neural leaf diagnosis with 98.2% confidence, crop yield cost calculators, and 3D canvas interaction.

### 4. OrgVault — Role-Based Knowledge Platform
*Enterprise operations and knowledge management system built for CSI GRIET leadership.*
- **Core Stack**: React, Node.js, Express, MongoDB, JWT Authentication
- **Impact**: Role-based access control (RBAC) matrix for Admin, Corporate Leads, and Technical Core teams; pitched and approved by society leadership.

## ✦ Quick Start / Local Setup

No Node.js build step or bundler is required. The project uses standard HTML5 with Tailwind CSS via CDN and Google Fonts.

### Option 1: Python HTTP Server
```bash
# Clone the repository
git clone https://github.com/manishbollikonda-318/my-portfolio.git
cd my-portfolio

# Start a local server
python3 -m http.server 3000

# Open in browser
open http://localhost:3000
```

### Option 2: Node / npx serve
```bash
npx serve . -p 3000
```

### Option 3: Direct File Opening
Double-click `index.html` to open it in Chrome, Safari, or Edge.

## ✦ Deployment

### GitHub Pages (Automated via GitHub Actions)
A pre-configured GitHub Actions workflow (`.github/workflows/deploy.yml`) is included.
1. In your GitHub repository, navigate to **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **GitHub Actions**.
3. Every push to the `main` branch will automatically deploy the site.

### Netlify
```bash
npx netlify-cli deploy --prod --dir=.
```

### Vercel
```bash
npx vercel --prod
```
